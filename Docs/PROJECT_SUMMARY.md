## 1. 一页结论

- 项目名称：**机械大师**；Slogan：**拆解万物，解锁机秘**。
- GitHub 仓库：<https://github.com/arsene56/mech-master>。先前给出的 `study-time` 链接是错误地址，不应再使用。
- 本地工程：`D:\Code\Mech.Master`；直接在 `main` 分支开发，**由项目所有者自行提交和推送**。不要代为提交。
- 目标平台是**微信小游戏**，不是普通网页或 Java 应用。技术基线为团结引擎 / Unity 2022 LTS、C# 运行时、Blender 4.5 LTS 建模、.NET 8 规则测试。尚无微信小游戏 AppID。
- 产品面向约 6–12 岁的儿童与青少年机械科普；模型写实仿真，界面可以更明亮、适合青少年，但机械结构不可卡通化。等级只叫**简单 / 进阶 / 探索**，不在等级名称或 README 的等级表里绑定年龄段。

## 2. 产品目标、范围和底线

### 2.1 核心体验

玩家能自由旋转、缩放和平移写实 3D 机械，点选具体零件查看中文名称、作用与原理；通过直接拖动把零件或子总成拆到对应分类展示区，再从展示区拖回组装。拆下的部件不能凭空消失，应在 3D 收纳区域分类摆放；接近对应底部分类槽时，槽位变色提示，松手提交。无论拆解还是组装，都允许**任选当前可操作单元**，不设强制顺序。

“1:1”指**源模型严格采用真实物理尺寸和比例**，运行时 1 Unity unit = 1 m；屏幕上允许自由缩放观察，并非要求在手机屏幕按现实尺寸显示。工程精度目标是可信的尺寸、接口、层级和拆装关系（维修训练级），不宣称原厂制造公差、材料应力、有限元或真实油液模拟。

当前样片包含硬尾自行车、Moveo、Bolt、OpenTorque 与 Carbon 软尾，框架让后续合格模型以独立清单、目录和资源接入。新增资源仅选择免费获取、允许修改和随本工程发行的模型。长期可考虑非电动汽车、燃油发动机、火车、飞机、轮船和钟表机芯；用户明确说**不要电动车**。新增模型的步骤数应依真实可拆结构确定，不机械套用自行车 15 / 30 / 45，也不虚构零件凑数。

### 2.2 明确排除

- 不加入星级、徽章、排行榜、连续登录、扣分惩罚、广告或付费抽取；重点是科普和拆装乐趣。
- 不把工具型号、规格、扭矩作为关卡门槛。界面历史文案“手”已改为“无需工具”；当前操作是**直接拖动**，工具类别仅可保留在 BOM 中供现实知识说明。内部旧枚举仍可能包含 `ToolKind` / `WrongTool`，不表示现行玩法要求匹配工具。
- 焊接、粘接、硫化、铆死结构不是常规可逆拆装步骤；密封轴承按维修单元处理。游戏不是现实维修教程，制动等安全关键内容需监护人或专业技师把关。
- 首版只用本地存档，不做账号、云同步或跨设备进度。

### 3.1 数量与拆装边界

- 14 个模块：车架、把组与碗组、避震前叉、前后轮、前后刹车、曲柄与中轴、前后拨链器、链条、脚踏、鞍座与座管、操控与线管。

- 前后轮分别保留 32 根辐条，链条保留链节、飞轮保留 10 片、牙盘保留 2 片，均有稳定身份与模型绑定。但即使在“探索”等级，辐条、链节、重复紧固件和内部小件也**作为合理子总成整体拆装**，不逐个拖动。
- 初期目标是整车所有模块达到维修训练级精密拆解；后续仍可继续改进曲面、铸件、齿片、线管和材质。不能把目前程序化模型宣称为某厂商原始 CAD。

三个等级对同一台车均要无遗漏、无重复地覆盖 595 个模型对象。等级不仅调整拆分粒度，也可调整科普深度：简单讲直观作用，进阶讲工作原理，探索讲结构细节或安全边界。**每次呈现的单段零件讲解不超过 50 个汉字**，不把三段长文叠加显示。历史按钮“重听当前零件”统一为“再次讲解”。

## 4. 操作、镜头、界面与反馈约定

1. 默认“旋转视角”：按住车身或空白处单指 / 鼠标左键拖动旋转；轻点零件选中、显示百科并触发讲解；滚轮 / 双指缩放。桌面右键始终可旋转。
2. 点击“拆装零件”：直接拖动机械单元，跟手移动，不应产生手指与零件的明显偏移；靠近所属分类槽时高亮，松手拆入。拖空白处仍可旋转。第二根手指加入或触摸取消时，不能错误提交拆装。
3. 组装时从 3D 分类展示位置拖回整车。现行实现以同一份已拆 ID 集合支持任意顺序装回；**先组装变速、减震等小部件，再组合为整车**的显式子计划仍是后续工作。
4. 左侧可收起的“拆解等级”及三维爆炸视图、右侧可收起的“零件小百科”、底部分类收纳、中央整车视图组成主界面。UI 采用更明亮的青少年配色；可有轻微卡通化的界面语言，但 3D 机械模型保持写实。左右栏和底部区应尽量不侵占整车取景。
5. 顶部“模型”选择位于“旋转视角”左侧；**只显示已交付且通过资源校验的模型**。最新布局已加宽模型文字并保持单行，最右操作提示垂直居中；左右侧栏重复的小标题已去掉，收起箭头保留。
6. “整机归位”重置观察取景而不更改拆装进度；整机默认取景相对居中位置向左偏移两个平移步长（96 个设计像素）。“查看收纳”纳入已拆零件和 3D 展示托盘并居中取景。右下角半透明“画面平移”提供上下左右和“中”：每次沿屏幕方向平移 48 个设计像素；“中”仅取消用户平移，保留角度及缩放；整机归位 / 查看收纳复位平移。
7. 全局一键爆炸：按当前模型/等级的逻辑单元展开 / 收回（自行车 15/30/45、Moveo 9/20/42、Bolt 12/23/42、OpenTorque 5/10/17）。OpenTorque 使用专用三级布局：简单分开五大模块，进阶将子组件沿轴分层并径向展开三套行星轮，探索再分开行星架板、压圈、齿轮/轴承与销轴组；初始侧向取景避免前后重叠，其它模型不变。点击单件爆炸：一次仅一个逻辑单元弹开，再点收回。爆炸只供观察，可继续旋转、缩放和平移；不改变拆解计数、已拆集合或存档，切至实际拆装、整机归位、查看收纳或切换等级时复位。
8. 拆装反馈使用简短机械音效，不采用泛用提示音。Windows Editor 已接本地中文系统语音；点击零件、成功拆装和“再次讲解”可播报。关闭讲解会停止当前播报。微信语音 / 已授权音频仍未接入。
9. UI 文字按真实渲染像素绘制：`PixelUILayout` 以 1920×1080 为设计基准，正文约 20 px（4K 约 40 px），不要用 `GUI.matrix` 放大低分辨率字形；Game View 用原生分辨率和 1x 预览检查清晰度。
10. 自行车已有固定 36T / 24T 的原地踩踏演示：仅完整整车可启动，可暂停、继续、结束并在 30–90 转/分间调速；曲柄、脚踏、运转链条、导轮、飞轮及前后轮默认联动。按住左刹把使后轮及联动传动逐渐停转，按住右刹把使前轮逐渐停转；松开后对应车轮逐渐恢复设定速度，两侧可同时按住。刹把与刹车片有对应动作。画面不额外生成脚撑或支架。演示链条显示层绕过两只后拨导轮，保留原有 110 个可拆链节及 595 实体基线。演示状态不写存档；转入拆装、爆炸、收纳或切换模型/等级时复位。
11. Moveo 关节演示仅在完整装配时可启动，循环驱动五个教学关节（底座、肩、肘、腕旋转、腕俯仰）和两侧夹爪四连杆；默认速度 1.00×（一轮约 10 秒，保持原 2.00× 的实际节奏），调速范围为相对新基准的 0.50×–1.50×，停止后恢复所有对象的源位置、旋转、父级和碰撞状态。演示以官方装配中的轴和支承件为约束，未模拟真实电机、负载、控制器、碰撞或动力学。
12. Bolt 关节演示仅在完整装配时可启动；每腿三个主动关节加一个被动踝轴，躯干固定。默认 1.00× 一轮约 6 秒，保持原 2.00× 的实际周期；调速和退出恢复规则同 Moveo。现为连续交替屈伸：17 个闭合关键帧通过周期、保形三次 Hermite 曲线衔接，关键帧和循环接缝的角速度连续，不再逐姿态全关节停住。髋膝错峰转向，被动踝直接补偿当前插值后的髋膝角度；不增加踝电机，不模拟地面接触、平衡行走、电机/皮带传动自转或完整动力学。
13. 演示结束后的拾取与局部爆炸已修复物理坐标刷新时序：项目关闭 `autoSyncTransforms`，故在停止演示并取消手势后、以及每次按下指针拾取前显式同步。仅恢复 `Collider.enabled` 不能保证射线命中当前显示位置；不能删除同步或在测试里额外同步来掩盖问题。

### 5.2 代码与数据架构

- `Assets/Scripts/Domain` 是不依赖引擎的纯 C# 状态机；拆装允许任意顺序，重复操作不改变状态，工具信息不参与校验。
- `MechMasterApp` 组合运行时；`MechanicalModelRegistry` 自动发现 `Assets/Resources/MechanicalCatalog/Models/*.json`；`MechanicalCatalogLoader` 载入各自三级交互目录；`MechanicalModelView`、`MechanicalPartView` 和 `MechanicalPartHitProxy` 将逻辑步骤绑定到真实 FBX 对象与碰撞热区。
- 运行时的 3D 托盘与相机构图以模型包围盒和装配清单驱动；分类超过 14 个时分页。每模型各自存档，按“模型 ID + 等级”隔离。新增合格模型原则上只添加 **1 个模型 JSON + 独立交互目录 + 分件 FBX/Prefab 等资产**，不用给主代码加 `switch`。
- `LocalProgressStore` 当前使用 Unity `PlayerPrefs` 保存所选模型、等级、讲解开关、模式及**准确的已拆步骤 ID 集合**。只存数字不够，因为拆装无固定顺序。爆炸状态不保存。
- UI 目前仍为 IMGUI 原型；长期应迁移到 UGUI 或 UI Toolkit。Windows Editor 讲解由本地 `WindowsSpeechHost` 实现，不可原样打包到微信。
- 动态演示由模型清单的可选 `motion` 配置启用：自行车使用 `bicycle-pedaling-v1`，Moveo 使用 `moveo-articulation-v1` / `MoveoMotionRig.json`，Bolt 使用 `bolt-articulation-v1` / `BoltMotionRig.json`。三者共享暂停、继续、结束、调速、停止时姿态复原和不写入拆装存档的接口；具体关节和刹车行为由各控制器实现。
- OpenTorque 另用 `opentorque-planetary-v1` / `OpenTorqueMotionRig.json`，`PlanetaryGearKinematics` 计算连续自转/公转，`OpenTorqueMotionController` 从源装配对象重建轴线。默认 1.00× 输入 60 rpm，输出 7.5 rpm，世界坐标行星轮自转 -10 rpm；调速 0.50×–1.50×。所有 Transform 闭合需要输入 24 圈，默认周期 24 秒。八件遮挡支承件临时透明且不投射遮挡阴影；退出恢复材质、阴影、高亮、源姿态和碰撞，不改变装配进度。单网格太阳轮需要专用导入设置保留层级和原名。不是转矩、接触或背隙仿真。
