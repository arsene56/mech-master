# 后续机械模型候选与入库门槛

更新日期：2026-09-22。首个已实现模型仍是自行车；以下两项尚未导入游戏，也不计入已交付内容。

## 统一验收条件

新增模型继续采用写实风格、米制 1:1 源尺寸、可自由旋转/缩放/平移、可逐件点击讲解及拆装。沿用「简单 / 进阶 / 探索」三档；步骤数量应从实际可拆零件及合理子总成推导，不用虚构零件凑数。每件模型都要完成以下核验，之后才能显示在正式模型选择菜单中：

1. 通过来源方许可的渠道取得原始 3D 文件，记录来源 URL、作者、版本、下载日期、许可证和文件校验值；不以预览图或第三方转存代替原件。
2. 核实原始文件的对象层级、分件边界、装配位置、单位和实测尺寸。外观细致但内部合并为整块的网格不合格。
3. 将重要结构、齿数/接口/外形尺寸与厂商或设计方的技术资料逐项对照；无法证明 1:1 尺寸时不得标称「工程仿真」。
4. 制作不改变结构关系的移动端 LOD 和材质，实测微信小游戏包体、内存、帧率、拾取精度及拆装交互。源文件和优化版都保留可追溯关系。
5. 建立逐件 BOM、中文名称与作用、三档分组、装配/爆炸锚点、回归测试和归属许可记录。

## OM10 机械腕表机芯：待取得与审计

- [openmovement 官方会员下载页](https://openmovement.org/member-downloads/)列有手动上链 OM10 MAN 的 STEP Version A/B，以及自动上链版本。下载仅对登录用户开放；[免费 User 等级](https://openmovement.org/membership-levels/)标注可访问 constructions。本项目没有创建账号或取得 STEP。
- [OM10 官方技术表](https://openmovement.org/documents/OM10/OM10_Technical_Information_20210314.pdf)给出手动版总直径 30.80 mm、高度 4.50 mm，以及轮系齿数、模数等核验基准。这使 1:1 尺寸审计有明确依据，但不能代替对 STEP 文件本身的检查。
- 技术表标注 CC BY-SA 3.0；但[协会说明](https://openmovement.org/wp-content/uploads/2021/08/OM_210830-OM10-EN.pdf)曾提出 STEP/Inventor 等电子文件可能另设许可。必须核对实际下载文件随附条款以及小游戏发行、改造网格和仓库存放是否被允许，不能直接把技术表许可推定为 STEP 许可。
- 需检查 STEP 是否保留逐件装配结构、紧固件/宝石/轮系完整度和原始材质信息；如无适用于游戏的材质，需要基于原始几何自行制作写实 PBR 材质。
- 这是腕表机芯，不是壁挂钟。正式命名和科普内容应准确区分。

## Tomaso V8 爆炸发动机：待取得与审计

- [原作者 Sketchfab 页面](https://sketchfab.com/3d-models/disassembled-v8-engine-block-3026bd87ca3945d6829d24c86ce695f0)标注免费可下载、CC BY 4.0、约 220 万三角面；[公开模型元数据](https://api.sketchfab.com/v3/models/3026bd87ca3945d6829d24c86ce695f0)显示无贴图、24 种材质。CC BY 允许改编和商业用途，但使用时需署名、附许可链接并说明修改。
- [Sketchfab 官方下载文档](https://sketchfab.com/developers/download-api/downloading-models)说明下载需要账号认证。本项目没有绕过认证，也未取得原始 glTF/源文件。
- 公开说明仅称「V8 engine block model」，未提供对应原厂发动机、缸径/行程或外形尺寸。当前不能验证「严格真实尺寸和比例」，也无法确认内部每件零件都可独立拆装。
- 原始面数远高于自行车现有移动端 LOD；需要分件保真降面、法线与材质重建、拾取代理及真机性能验证。优化前不可直接作为微信小游戏运行资源。

## 当前决定

两者都是候选，不是已通过验收的游戏模型；不创建空白模型入口或低精度替身。拿到合法原始文件并完成上述审计后，可分别接入模型选择、独立目录/存档、三档拆装和讲解。若 V8 不能建立真实尺寸依据，应改选有型号与尺寸资料的燃油发动机，而不是任意缩放它来声称 1:1。

通用模型接入层已完成：运行时自动发现各模型清单，由清单指定分件资源、三级拆装目录和分类；相机与 3D 托盘按模型包围盒缩放，存档按「模型 ID + 拆解等级」隔离。旧自行车本地存档可迁移读取。两个候选依旧不能仅凭公开预览图入库；需要先取得原件并逐项通过上面的验收。
