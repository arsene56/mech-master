## 取得原件后再执行的验收

1. 记录官方来源、实际格式、下载日期及 SHA-256，核对随包许可与页面许可一致。
2. 在 Blender 审计对象、网格、材质、重复实例及连通分量；确认前车架、后摇臂、上下连杆、后胆两端、前叉内外管和车轮能分别绑定。页面评论中有人请求上下连杆模型，仅提示分件风险，不能据此判定连杆缺失或存在。
3. 确认车型代际、尺码、单位和可信的尺寸依据；不套用现有硬尾车参数，也不随意放大后宣称 1:1。没有依据时记录未知，不标称工程仿真。
4. 检查悬架铰点、轴线和运动范围是否能够由源几何与对应技术资料确定。缺失关键运动件或整体合并的外观网格不能直接验收；密封避震器可作为维修总成，不虚构内部件或凑步骤。
5. 通过上述审计才生成 Source、分模块 LOD0、整车 LOD1/LOD2、中文 BOM、三级拆装目录、绑定与独立存档。保留现有硬尾车型，V10 作为独立模型接入；步骤数量由真实结构决定。
6. 若可建立可信悬架绑定，再实现前后避震运动学演示；停止后恢复姿态、材质、碰撞和拾取状态，复测演示后单件爆炸与直接拖放。未验证的演示不创建可用按钮。
7. 执行源尺寸/完整覆盖验证、.NET 内容规则及隔离 Editor 三档拆装/爆炸/保存/复原回归，确认旧四模型不回退。微信包体、真机性能和触摸验收仍是独立后续门槛。
