# 音频资产规范

当前样片使用程序生成的简短拆装反馈音，不包含外部音频文件。Windows Editor 已接入本地中文讲解：`VoiceNarrator` 通过 `WindowsSpeechHost` 调用已安装的系统中文语音，点击零件、成功拆装或点击“再次讲解”时播报；关闭讲解会停止当前播报。`LocalSpeechBuilder` 将辅助程序编译到不提交的 `Library/MechMaster/`，不联网，也不再分发系统语音文件。

此语音实现仅适用于 Windows Editor。微信小游戏尚需接入已授权的中文音频或平台语音服务，并在真机上验证播放、缓存及前后台恢复。依赖和排查方法见[开发与验证](../../Docs/DEVELOPMENT.md#windows-editor-中文讲解)。

新增音频时必须：

- 优先使用原创录音或明确允许商用、修改和再分发的素材。
- 保存作者、来源 URL、许可证名称、下载日期和修改记录。
- 不使用来源不明的网络音频。
- 对儿童内容控制音量和刺激强度，不使用突然、尖锐或带惩罚感的失败音效。
- 导入前转换为移动端友好的采样率和单声道/立体声配置。
- 在微信真机上验证解码时间、内存和循环播放行为。

建议在本目录新增 `ATTRIBUTION.md` 统一登记第三方音频信息。
